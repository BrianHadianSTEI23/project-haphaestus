- **`world_models_fpga/research/benchmarks/results/task_conditioned_closed_loop_grounding_v5_5_1_cohort_report.json`**: Candidate evaluation counts (`755` evaluated, `695` rejected, `60` accepted), rejection reasons, separation/distance ranges, `min_init_visible_px`, and Oracle A/B pass counts (`60/60`, `60/60`).
- **`world_models_fpga/research/benchmarks/results/task_conditioned_closed_loop_grounding_v5_5_1_summary.json`**: Provenance hashes, cohort report, per-condition aggregates & stratifications (`by_context`, `by_assignment`, `by_assigned_side`, `by_target_category`, `by_category_pair`, `by_outcome`), `confirmatory_hypothesis_families_holm5` (`H1`–`H5`), `trace_export`, and `representative_cases`.

- **`task_conditioned_closed_loop_v5_5_1_traces.npz`** (`32,438,915` bytes): Keyed by `<condition>__<scene_id>__<assignment>__<field>` with arrays (`pose`, `latent_s`, `task_embedding`, `grounding_latent`, `l1_act`, `l2_act`, `g_visual`, `g_memory`, `g_blended`, `planner_goal`, `delta_ego`, `gt_assigned_body`, `gt_unassigned_body`, `a_react`, `action_exec`, `best_macro_idx`, `pred_macro_disp`, `pred_micro_disp`, `col_risk`, `dist_assigned_wp`, `dist_unassigned_wp`, `assigned_vis_px`, `unassigned_vis_px`, `masked_px`, `fallback_mask`, `action_assigned_cos`, `action_unassigned_cos`, `goal_ang_err_rad`, `vis_ang_err_rad`, `planner_goal_ang_err_rad`, `proj_signed_vis_m`, `proj_signed_blended_m`, `coord_vis_norm`, `coord_blended_norm`, `task_embedding_executed`, `grounding_head_executed`, `memory_branch_executed`). Unexecuted `g_memory` and `delta_ego` entries are `NaN`.
- **`task_conditioned_closed_loop_v5_5_1_trace_export/`** (`39` shards + `shard_manifest.json`): Plain-text `.jsonl` step-by-step export (`32,557` rows, `max_observed_shard_bytes = 4,199,903 < 5 MB`), using JSON `null` for `NaN`/unexecuted values.
- **`task_conditioned_closed_loop_v5_5_1_representative_keyframes.npz`**: Saved RGB keyframes for `correct_selection_ep` (`SCENE_000`, `B`), `incorrect_selection_ep` (`SCENE_006`, `B`), `failure_ep` (`SCENE_000`, `A`), and `task_switch_comparison` (`SCENE_026`).
