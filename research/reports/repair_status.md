## Status Legend

- `VERIFIED_FIXED`: Issue has been repaired in code, executed, and verified by automated tests and/or empirical artifacts.
- `PARTIALLY_FIXED`: Code repair was partially started on `fix/interpretability`, but remaining flaws or unexecuted regeneration steps remain.
- `IMPLEMENTED_NOT_EXECUTED`: Code exists or was repaired, but the full experiment or synthesis has not yet been executed.
- `EXECUTED_BUT_INVALID`: Historical artifact was produced by an executed script, but methodological flaws invalidate its scientific conclusion.
- `HARDCODED_OR_SYNTHETIC`: Script outputs literal constants or synthetic random samples rather than empirical measurements.
- `CONTRADICTED`: Empirical or code inspection directly contradicts the claimed mechanism or algorithm.
- `NOT_IMPLEMENTED`: Claimed capability or check is absent from the implementation.
- `BLOCKED`: Cannot be executed due to external hardware/software constraints.
