## 3. Physical Counterfactual Verification (`E1`–`E7`)

Executed via [validate_counterfactuals.py](file:///home/hadynata/vs-code-data/hdl/project-haphaestus/world_models_fpga/research/datasets/counterfactual/validate_counterfactuals.py) and [test_counterfactual_physics.py](file:///home/hadynata/vs-code-data/hdl/project-haphaestus/world_models_fpga/world_models_fpga/tests/test_counterfactual_physics.py) across multiple `pair_id` values (`0, 3, 12, 24`):

1. **`E1_position_shift`**: Target `obs_yellow_cyl` physical position in `model.geom_pos` changes from `[-1.2, -0.9, 0.35]` to `[0.8, -1.2, 0.35]`, and rendered $64 \times 64 \times 3$ camera RGB image changes (`max_abs_diff > 0`).
2. **`E2_color_shift`**: Target `obs_yellow_cyl` `model.geom_rgba` changes from `[0.95, 0.85, 0.1, 1.0]` to `[0.15, 0.35, 0.85, 1.0]`, and rendered RGB observation changes while geometry positions remain identical.
3. **`E3_robot_rotation`**: Robot initial yaw `data.qpos[jz_id]` rotates by $+\pi / 2$ rad ($90^\circ$), and rendered RGB observation changes while arena geometry remains identical.
4. **`E4_robot_position`**: Robot initial planar coordinates `data.qpos[jx_id, jy_id]` shift to the opposite quadrant, and rendered RGB observation changes.
5. **`E5_intermediate_obstacle`**: Reserved collidable geometry `obs_inserted` moves from `[0, 0, -10]` below the floor to the active line-of-sight midpoint `[mid_x, mid_y, 0.35]` in the arena, visibly alters the rendered RGB observation, and triggers physical collision in `JetAutoEnv._check_collision()` when the robot occupies its coordinates.
6. **`E6_shape_mutation`**: Target `obs_yellow_cyl` `model.geom_type` changes from `mjGEOM_CYLINDER` to `mjGEOM_BOX` (`size = [0.25, 0.25, 0.35]`), altering the rendered silhouette and contact geometry.
7. **`E7_camera_viewpoint`**: Front camera quaternion `model.cam_quat[front_camera_id]` rotates by $+10^\circ$ pitch in local frame, shifting the rendered visual horizon while physical positions remain unchanged.

## 4. Label Provenance & Split Disjointness

- **Label Provenance:** Ground-truth actions in `splits_v2` are generated by the deterministic geometric planner [ExpertNavigator](file:///home/hadynata/vs-code-data/hdl/project-haphaestus/world_models_fpga/research/datasets/generation/expert_navigator.py) using privileged simulator poses and obstacle clearances. They are explicitly labeled in all metadata files as `"privileged_geometric_expert; simulator state used only for labels"` and are treated strictly as privileged Track A demonstrations, never as evidence of learned visual reasoning.
- **Zero Leakage Guarantee:** Split assignment operates strictly at the episode level (`i % 6 < 4` train, `i % 6 == 4` val, `i % 6 == 5` held-out test, `seed_idx >= 9000` independent validation). `verify_dataset.py` enforces `assert not left_ids & right_ids` and `assert not left_seeds & right_seeds` across all splits.
