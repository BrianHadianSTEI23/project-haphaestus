# Project Hephaestus research program

This project investigates whether action-conditioned visual models acquire reusable computational mechanisms for spatial relation, future prediction, navigation, and safe action selection. Its central claim is not that a compact model or RTL simulation is intelligent; every claim must trace from observation through representation and intervention to reproducible behavioral evidence.

The repair sequence is environment validity, valid training, information-bounded behavior, representation/circuit interventions, independent principle tests, architecture reconstruction, then hardware equivalence. Existing artifacts are historical and remain preserved. See `audit/repair_status.md` for their current evidence status and `hypotheses/research_hypotheses.md` for preregistered falsification criteria.
